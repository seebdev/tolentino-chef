# Fotografías y contenido de las muestras

Actualización: 25 de octubre de 2026. Estado: 49 archivos subidos, aún sin vincular al catálogo público.

Hay 46 productos de muestra con fotografías revisadas y 26 sin correspondencia adecuada, que se mostrarán sin fotografía. Los 123 productos importados quedan excluidos. No se usaron fotos de Crepes ni imágenes generadas. Los tres logos propios se limpiaron retirando sólo DEMO. Se conservaron portadas, colores elegidos, precios, extras, variantes, identificadores, slugs y tokens QR.

El inventario comprobó bytes SHA256 de las ilustraciones originales antes de reemplazarlas. Las fotos se subieron con las sesiones de cada propietario; se verificaron de nuevo los bytes después del procesamiento del servidor. Se conservan todos los objetos históricos. Los textos sólo se limpian cuando coinciden exactamente con la semilla, incluidas 72 descripciones inglesas manuales conocidas; las demás traducciones no se sobrescriben.

[Plan verificable](evidence/closure-demo-photo-plan.json), diario privado .runtime/migrations/hgntppemxwcxaxritnfq/closure-photo-uploads.json y manifiesto público public/photo-credits.json. Los créditos deben estar desplegados antes de vincular fotos. El script de aplicación bloquea si faltan y utiliza una transacción con comparaciones de cada campo esperado.

Las imágenes son representativas del plato; no certifican recetas, alérgenos o que procedan de la cocina del restaurante. Se descartaron marcas ajenas y contradicciones observables. Las ausencias de un ingrediente interno en una foto no se interpretan como prueba de su ausencia.
